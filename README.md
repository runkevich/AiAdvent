# AI Advent

Небольшой проект для экспериментов с моделями OpenAI и промптами. В него входят веб-приложение **Everyday AI Lab** и простой консольный чат.

## Что есть в проекте

- **День 2 — формат ответа.** Сравнение вариантов одного промпта с разными ограничениями формата.
- **День 3 — reasoning.** Запуск задач с разными уровнями reasoning и анализ результатов.
- **День 4 — температура.** Сравнение ответов модели при разных значениях temperature.
- **День 5 — модели.** Сравнение нескольких моделей OpenAI на общих задачах; доступны результаты и аналитика.
- **День 6 — первый агент.** Веб-чат с циклом вызова инструментов: текущее время, калькулятор и поиск по списку задач.
- **День 7 — сохранение контекста.** Полная история Responses API сохраняется по чатам в JSON, включая вызовы инструментов и результаты.
- **День 8 — работа с токенами.** Локальная оценка через `o200k_base`, фактический usage API, стоимость и проверка учебного лимита контекста.
- **День 9 — сжатие истории.** Сравнение полной истории и summary с проверкой сохранения фактов.
- **День 10 — стратегии и ветвление.** Sliding Window, Sticky Facts и Summary в независимых ветках диалога.
- **День 11 — слои памяти.** Отдельные краткосрочная, рабочая и долговременная память, импорт facts из Дня 10, состав prompt и токены каждого слоя.
- **День 12 — персонализация.** Профиль пользователя с предпочтениями по длине, коду и тону; обучение из диалога, сравнение профилей и проверка устойчивости.
- **Консольный чат.** Отправка одного вопроса модели и вывод ответа в терминал.

Веб-интерфейс и сервер написаны на Kotlin с Ktor. Запросы к OpenAI выполняются через API; результаты экспериментов можно просматривать в интерфейсе.

## Требования

- JDK 26
- API-ключ OpenAI

Ключ можно передать через переменную окружения `OPENAI_API_KEY`, сохранить в локальном файле `.env` в каталоге `AiAdvent` или использовать macOS Keychain (имя записи `AiAdvent-OpenAI`). Источники проверяются в таком порядке: переменная окружения, `.env`, Keychain.

Чтобы сохранить ключ в `.env`, создайте этот файл рядом с `build.gradle.kts` и добавьте строку:

```dotenv
OPENAI_API_KEY=sk-ваш-ключ
```

Файл `.env` исключён из Git, поэтому ключ не попадёт в коммит. Не добавляйте его содержимое в сообщения, скриншоты или репозиторий.

## Запуск

Перейдите в каталог проекта:

```bash
cd AiAdvent
```

Запустить веб-лабораторию:

```bash
./gradlew runWeb
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). Порт можно изменить переменной `PORT`.

В разделе Дня 7 задайте вопрос с вызовом инструмента, остановите и снова запустите сервер, затем обновите страницу. Продолжите тот же чат: веб-клиент сохраняет его ID, а сервер восстанавливает историю из `results/day7/`.

В разделе Дня 8 отправьте короткий пример, затем длинную реплику три или четыре раза. Сравните оценку истории с фактическими input/output tokens и стоимостью. Учебный предел 8 000 токенов останавливает запрос до обращения к API; переключатель «Предел модели» использует размер контекста GPT-4.1. Метрики сохраняются в `results/day8/`.

В Дне 11 сначала создайте сессию. Если в браузере есть созданная ветка Дня 10, её Sticky Facts импортируются в долговременную память; иначе используется тот же учебный набор facts. Сохраните по одной записи в каждый слой, отправьте запрос и сравните токены. Затем очищайте слои по очереди и запускайте три контрольных вопроса: после очистки соответствующего слоя агент должен ответить «не помню».

В Дне 12 создайте три контрастных профиля и отметьте их для сравнения. Один и тот же вопрос вызовет отдельный запрос для каждого профиля, а экран посчитает ответы, прошедшие проверку длины, кода и обращения «ты»/«вы». Затем выберите один профиль и проверьте десять ответов подряд. Предпочтения можно изменить прямо в сообщении, например: «отвечай подробно, без кода, на вы».

Запустить консольный чат:

```bash
./gradlew run
```

## Структура

- `src/main/kotlin/day2` – эксперименты с форматированием промптов
- `src/main/kotlin/day3` – задачи и анализ reasoning
- `src/main/kotlin/day4` – эксперименты с temperature
- `src/main/kotlin/day5` – сравнение моделей и результаты
- `src/main/kotlin/day6` – агент и его инструменты
- `src/main/kotlin/day7` – JSON-хранилище и агент с восстановлением истории
- `src/main/kotlin/day8` – токенизатор, статистика и хранение замеров
- `src/main/kotlin/day9` – summary-память и проверка сохранения фактов
- `src/main/kotlin/day10` – стратегии контекста, facts и ветвление
- `src/main/kotlin/day11` – изолированные слои памяти и контроль их состава
- `src/main/kotlin/day12` – профиль пользователя, обучение предпочтениям и сравнение ответов
- `src/main/resources/web` – веб-интерфейс
- `src/test` – автоматические тесты
