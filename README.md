# AI Advent

Небольшой проект для экспериментов с моделями OpenAI и промптами. В него входят веб-приложение **Everyday AI Lab** и простой консольный чат.

## Что есть в проекте

- **День 2 — формат ответа.** Сравнение вариантов одного промпта с разными ограничениями формата.
- **День 3 — reasoning.** Запуск задач с разными уровнями reasoning и анализ результатов.
- **День 4 — температура.** Сравнение ответов модели при разных значениях temperature.
- **День 5 — модели.** Сравнение нескольких моделей OpenAI на общих задачах; доступны результаты и аналитика.
- **Консольный чат.** Отправка одного вопроса модели и вывод ответа в терминал.

Веб-интерфейс и сервер написаны на Kotlin с Ktor. Запросы к OpenAI выполняются через API; результаты экспериментов можно просматривать в интерфейсе.

## Требования

- JDK 26
- API-ключ OpenAI

Ключ можно передать через переменную окружения `OPENAI_API_KEY`. На macOS приложение также умеет читать его из Keychain под именем `AiAdvent-OpenAI`.

## Запуск

Перейдите в каталог проекта:

```bash
cd AiAdvent
```

Запустить веб-лабораторию:

```bash
./gradlew runWeb
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). Порт можно изменить переменной `PORT`.

Запустить консольный чат:

```bash
./gradlew run
```

## Структура

- `src/main/kotlin/day2` – эксперименты с форматированием промптов
- `src/main/kotlin/day3` – задачи и анализ reasoning
- `src/main/kotlin/day4` – эксперименты с temperature
- `src/main/kotlin/day5` – сравнение моделей и результаты
- `src/main/resources/web` – веб-интерфейс
- `src/test` – автоматические тесты
