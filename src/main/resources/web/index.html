        Задание · День 11
        Модель памяти ассистента
        Создайте сессию
        
      
        Три слоя хранятся в отдельных полях: краткосрочный диалог, рабочие данные задачи и долговременные facts. Каждый запрос показывает вклад слоёв в контекст.
        
      
        
      
        При наличии сохранённых Sticky Facts из Дня 10 они будут импортированы; иначе загрузится тот же учебный набор facts.
        
      
        
        
        Краткосрочная
        Последние 6 сообщений текущего диалога. Не содержит состояния задачи и постоянных facts.
        
        
        Рабочая
        Полный снимок активной задачи: задача, этап, следующий шаг. Передаётся в каждом запросе задачи.
        
        
        Долговременная
        Проверенные facts из Дня 10. Передаётся как справка, новые сведения туда не попадают автоматически.
        
      
        
      
        
        
        Краткосрочная память
        0 токенов
        
        
        Рабочая память
        0 токенов
        
        
        Долговременная память
        0 токенов

        Задание · День 12
        Персонализация ассистента
        Создайте профили
        
      
        Профиль — отдельная долговременная память пользователя поверх слоёв Дня 11. Он добавляется в каждый запрос и может обновиться прямо из диалога.
        
      
        
        
        
        
        
      
        
      
        Профили сохраняются локально. Для сравнения отметьте два или три профиля.
        
      
        
      
        
        
        Диалог и обучение профиля
        Выберите активный профиль. Фраза «отвечай подробно, без кода, на вы» обновит его и отметит источники как «из диалога».
        
        
        
        
        
        Ответ
        
      
        
      
        
        
        Сравнение одинакового вопроса
        
        
        
        
        
      
        
      
        
        
        Устойчивость профиля
        Отправляет десять последовательных вариантов вопроса активному профилю и фиксирует первый ответ, не прошедший три проверки.
        
        
        
        
        
      
        
    
        

    
        
      
        Задание · День 13
        Состояние задачи — конечный автомат
        Создайте задачу
        
      
        Этап меняется только кодом: планирование → реализация → валидация → завершено. Сообщение ассистенту не может обойти эти правила.
        
      
        
        
        
        
        
      
        
      
        Переходы до утверждения плана и до валидации будут отклонены.
        
      
        
        
        Планирование→Реализация→Валидация→Завершено
        
        
        —
        Текущий шаг: —
        Ожидаемое действие: —
        
        
        
      
        
      
        Проверка реакции ассистента
        Попросите его нарушить порядок: состояние останется прежним, потому что переход не происходит через текстовый ответ.
